# User guide visual assets

Visuals in this folder are privacy-safe representative captures of the current LeaveMaestro UI, built from the actual labels, controls and workflow structure in the frontend source. They intentionally use fictional demo values and contain no production employee data, email addresses, secrets, PINs or tokens.

When the UI changes materially, update the matching visual together with the user-guide instructions so the asset remains accurate. Keep filenames stable where possible because user-guide pages may deep-link to these assets.
