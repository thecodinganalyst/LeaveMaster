# LeaveMaestro User Guide

Use this section to learn how to use LeaveMaestro as an employee, manager, HR user, or tenant administrator.

The User Guide is organized by the task you want to complete and the role you use in LeaveMaestro. Detailed step-by-step guides are being added separately so this shared documentation structure can remain stable as the product evolves.

## Choose your area

- [Getting Started](getting-started/index.md) — signing in, account activation, and understanding your access.
- [Employees](employee/index.md) — leave balances, leave requests, and your leave calendar.
- [Managers](manager/index.md) — reviewing leave and viewing team information available to managers.
- [HR](hr/index.md) — staff setup, entitlements, approvers, and HR-managed leave information.
- [Administrators](admin/index.md) — tenant leave configuration and administration.
- [Account & Security](account-security/index.md) — login, account activation, and connected sign-in providers.
- [Troubleshooting](troubleshooting/index.md) — help with common user-facing problems.
